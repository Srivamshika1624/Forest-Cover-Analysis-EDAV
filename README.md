# Forest Cover Analysis – EDAV

## Project Overview
This project focuses on Exploratory Data Analysis and Visualization of forest cover in India using Python.

## Dataset
- Forest Coverage (1987–2013).xlsx

## Technologies Used
- Python
- Google Colab
- NumPy
- Pandas
- Matplotlib
- Seaborn
- GeoPandas

## Project Files
- `Forest_Cover_Analysis_EDAV_(2).ipynb`
- `Forest Coverage (1987-2013).xlsx`
- `forest-coverage-india-geopandas.ipynb`

## How to Run
1. Open the notebook files in Google Colab.
2. Upload the required dataset.
3. Run the notebook cells sequentially.
